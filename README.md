# 🎉 Aniversário

Página comemorativa desenvolvida com **React, TypeScript e Tailwind CSS**, com animações e efeitos de confete para criar uma experiência interativa de aniversário.

## ✨ Recursos

- Experiência dividida em etapas
- Transições animadas entre telas
- Partículas e elementos decorativos
- Efeito de confete
- Interface responsiva

## 🛠️ Tecnologias

<div><img src="https://skillicons.dev/icons?i=react,typescript,vite,tailwind" /></div>

- React 19
- TypeScript
- Vite
- Tailwind CSS 4
- Framer Motion
- Canvas Confetti
- Lucide React

## ⚙️ Executando localmente

```bash
git clone https://github.com/marcosfrancomarinho/aniversario.git
cd aniversario
npm install
npm run dev
```

## 💡 Objetivo

Projeto desenvolvido para praticar animações, controle de estado, interações visuais e criação de experiências responsivas com React.
